# 18 — Pilot: World Wide Associates · TAXIS & ΟΠΣΚΕ

**Πελάτης pilot:** World Wide Associates Ε.Ε. (WWA) — σύμβουλοι ΕΣΠΑ/κρατικών ενισχύσεων. Χειρίζονται πολλούς δικαιούχους, άρα πολλά σετ διαπιστευτηρίων και επαναλαμβανόμενες καταχωρίσεις.
**Συστήματα‑στόχοι:** **TAXIS** (ΑΑΔΕ / TaxisNet) και **ΟΠΣΚΕ** (Ολοκληρωμένο Πληροφοριακό Σύστημα Κρατικών Ενισχύσεων, `app.opske.gr`).
**Domain:** `https://complete.dgsmart.gr`.

## 1. Τα δύο συστήματα

| | TAXIS (ΑΑΔΕ) | ΟΠΣΚΕ |
|---|---|---|
| URL | myAADE / TaxisNet (`*.aade.gr`), σύνδεση μέσω `*.gsis.gr` | `app.opske.gr` (πληροφορίες: `opske.gr`) |
| Σύνδεση | Κωδικοί TaxisNet του δικαιούχου (ή εξουσιοδοτημένου λογιστή/συμβούλου) | Κωδικοί TaxisNet· χρήστης με ρόλο στον δικαιούχο |
| Ρόλοι στο σύστημα | Φορολογούμενος / εξουσιοδοτημένος | Δικαιούχος, **Συντονιστής** (υποβάλλει αιτήσεις & αιτήματα), **Οικονομικός Υπεύθυνος** (παραστατικά, δικαιολογητικά) |
| Τυπικές καταχωρίσεις (υποψήφιες ροές) | Λήψη βεβαιώσεων (π.χ. φορολογική/ασφαλιστική ενημερότητα όπου διατίθεται), στοιχεία μητρώου/ΚΑΔ, δηλώσεις όπου επιτρέπεται | Δημιουργία/συμπλήρωση αίτησης χρηματοδότησης, αιτήματα τροποποίησης, αιτήματα προκαταβολής και καταβολής ενίσχυσης, ανέβασμα παραστατικών/δικαιολογητικών, IBAN |
| Ιδιαιτερότητες | Πιθανός δεύτερος παράγοντας (OTP/κλειδάριθμος) σε ορισμένες υπηρεσίες → `humanTask` | Μακριές φόρμες με πολλές καρτέλες, ανέβασμα αρχείων, πίνακες δαπανών (forEach), αυτόματα προσυμπληρωμένα πεδία από άλλα κρατικά συστήματα |

> Οι ακριβείς ροές του pilot ορίζονται με την WWA στην πρώτη συνάντηση χαρτογράφησης (λίστα «top 5 επαναλαμβανόμενες καταχωρίσεις»). Όπου η ΑΑΔΕ προσφέρει επίσημο API/web service (π.χ. myDATA, αναζήτηση στοιχείων ΑΦΜ), προτιμάται το API αντί για αυτοματοποίηση οθονών.

## 2. Διαπιστευτήρια πολλών δικαιούχων

Η WWA δουλεύει για πολλούς δικαιούχους, οπότε:
- `Credential` αποκτά **`externalRef`** (π.χ. ΑΦΜ δικαιούχου) και **`tags[]`**· μοναδικό ανά (tenant, σύστημα, externalRef).
- Το API δέχεται `credentialRef`: `POST …/runs { "input": {...}, "credentialRef": "afm:094014201" }` — ο worker βρίσκει το σωστό σετ κωδικών. Σε batch jobs η στήλη ΑΦΜ του Excel αντιστοιχεί αυτόματα σε `credentialRef`.
- **Απόφαση:** η WWA μπαίνει και στο ΟΠΣΚΕ και στο TAXIS **με τους κωδικούς κάθε δικαιούχου** — δεν χρησιμοποιείται λογαριασμός συντονιστή. Κάθε ροή ξεκινά με login του συγκεκριμένου δικαιούχου· δεν χρειάζεται ροή «Επιλογή δικαιούχου».
- Αν λείπει credential για το `credentialRef` → 422 `E_CREDENTIAL_NOT_FOUND` πριν την ουρά (δεν χρεώνεται).
- Όριο ταυτόχρονων sessions ανά credential = 1 (τα κρατικά συστήματα συχνά αποσυνδέουν παράλληλα logins).
- Μαζική εισαγωγή διαπιστευτηρίων από Excel (ΑΦΜ, επωνυμία, username, password) από TENANT_ADMIN, με κρυπτογράφηση στην εισαγωγή και διαγραφή του αρχείου μετά το parsing.

## 3. Νομικά & λειτουργικά

- **Εξουσιοδότηση:** για κάθε δικαιούχο η WWA δηλώνει ότι έχει εξουσιοδότηση χρήσης των κωδικών του (πεδίο `authorizationRef` / ημερομηνία στο credential, υπενθύμιση λήξης).
- **Όροι χρήσης κρατικών συστημάτων:** throttling (`minDelayMs` ≥ 500 ms), λογικός αριθμός ταυτόχρονων εκτελέσεων ανά σύστημα (default 2), εκτελέσεις εκτός ωρών αιχμής για μεγάλα batch.
- **Ευαίσθητα δεδομένα:** στιγμιότυπα TAXIS με masking όλων των αριθμητικών στοιχείων ταυτότητας· `ai.sendScreenshots = false` για TAXIS.
- **Αλλαγές UI:** τα κρατικά συστήματα αλλάζουν χωρίς προειδοποίηση → health runs, incidents και αυτόματη παύση μεθόδων κατά **docs/23** (ωριαία στο ωράριο εργασίας). Παλαιότερη διατύπωση: nightly «health run» σε δοκιμαστικό δικαιούχο της WWA (από τη φάση 3 μεταφέρεται νωρίτερα για το pilot) και alerts.

## 4. Πλάνο pilot

| Βήμα | Περιεχόμενο | Αποτέλεσμα |
|---|---|---|
| 1 | Workshop χαρτογράφησης με WWA | Λίστα ροών (3 ΟΠΣΚΕ + 2 TAXIS), δείγματα δεδομένων |

| 5 | Μαζική εκτέλεση από Excel | Ένα πραγματικό batch με report |
| 6 | Αξιολόγηση & πακέτο | Ενεργοποίηση πακέτου, χρέωση μέσω SoftOne |

**Κριτήρια επιτυχίας:** ≥ 95% επιτυχία στις ροές του pilot, διάγνωση κάθε αποτυχίας από τη σελίδα εκτέλεσης χωρίς πρόσβαση στον κώδικα, χρόνος καταγραφή → δημοσιευμένη μέθοδος < 1 ημέρα ανά ροή.
